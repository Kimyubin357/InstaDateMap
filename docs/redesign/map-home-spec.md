# 지도 홈·장소 상세 — 기능·시퀀스 명세 (시안 입력용)

작성: 2026-11-07. 시안 작업을 시작하는 기준 문서입니다.

이 문서는 **현재 화면의 배치를 일부러 담지 않았습니다.** 버튼 위치·시트 높이·색·서체는 적지 않고, 사용자가 하려는 일과 필요한 정보, 상태, 흐름만 정의합니다. 시안을 만드는 사람(또는 에이전트)은 이 문서만 보고 배치를 새로 설계합니다. 기존 `src/` 코드와 화면 캡처는 참고하지 않습니다.

## 0. 시안 작업 규칙

- **범위:** 지도 홈, 장소 미리보기, 장소 상세, 필터, 그리고 장소 등록을 마치고 지도로 돌아오는 순간.
  - 등록 화면 자체(링크 입력·후보 확인)는 별도 과제라 이번 범위가 아닙니다.
  - 리스트 탭은 진입점만 표시합니다.
- **표현 수준:** 회색조 와이어프레임입니다. 판단 대상은 위치·순서·단계 수·정보 우선순위이며, 색과 장식은 판단 대상이 아닙니다.
  - 상태 4종을 구분하는 표시는 모양·글자·패턴처럼 색 없이 구분되는 방식으로 표현합니다. 최종 색은 기존 테마가 정합니다.
- **화면 크기:** 세로 320×568, 393×852와 가로 568×320, 667×375, 844×390, 932×430을 모두 설계합니다.
  - 가로를 세로의 늘린 버전으로 만들지 말고, 가로에서 따로 배치를 정합니다.
  - 좌우 노치(안전영역) 59px, 하단 홈 표시줄 21px을 가정합니다.
- **조작 기준:** 터치 영역은 최소 44×44px, 인접한 터치 영역 사이는 8px 이상 띄웁니다. 한 손(엄지)으로 자주 쓰는 동작이 닿는지 고려합니다.
- **문구:** 한국어로 짧게 씁니다. 오류 문구는 사용자 안내만 쓰고 기술 용어는 쓰지 않습니다.
- **기능 보존:** 아래 기능 목록에 있는 것은 하나도 빠지면 안 됩니다. 기능을 합치거나 옮기는 것은 자유입니다.

## 1. 앱과 사용자

- 커플 두 사람이 함께 쓰는 "가고 싶은 곳·다녀온 곳" 지도입니다. 주로 아이폰 홈 화면 앱(PWA)으로 씁니다.
- 장소는 두 가지 방법으로 쌓입니다.
  - 인스타그램 링크를 넣으면 장소를 자동으로 찾아 저장합니다. 한 링크에서 여러 곳이 나오기도 합니다.
  - 카카오 장소 검색으로 직접 저장합니다.
- 상대가 새 장소를 저장하면 알림이 옵니다. 그래서 "상대가 방금 뭘 넣었지?"를 확인하는 일이 잦습니다.
- 지도는 카카오 지도입니다. 지도 위 표시물(핀 등)은 HTML로 자유롭게 그릴 수 있습니다.

## 2. 장소 데이터 (화면에 쓸 수 있는 정보)

| 항목 | 설명 |
|---|---|
| 이름 | 상호명. 길 수 있음 (예: "딩티엔 용산아이파크몰점") |
| 주소 | 도로명 주소 |
| 좌표 | 위도·경도 |
| 종류 | 카카오 분류에서 가져온 짧은 이름 (음식점·카페·전시 등). 없을 수 있음 |
| 상태 | 4종 중 하나. 가고 싶음 / 다녀옴 / 또 갈래 / 별로. 새로 저장하면 "가고 싶음" |
| 메모 | 두 사람이 함께 고치는 메모 한 개. 최대 500자. 동시에 고치면 충돌 안내 |
| 저장한 사람 | A님 / B님 / 둘 다 저장함 |
| 원본 | 인스타 게시물 링크 0개 이상 |
| 등록 시각 | 등록 후 24시간 동안은 "새로 등록한 장소"로 취급 |
| 모음 | 사용자가 만든 묶음(예: "성수 카페"). 한 장소가 여러 모음에 들어갈 수 있음 |
| 행정구역 | 좌표로 조회한 시·군 / 구 / 읍·면·동. 조회가 늦거나 실패할 수 있음 |

## 3. 지도 홈에서 할 수 있어야 하는 일

1. 저장한 장소들을 지도에서 한눈에 보기. 처음 열면 모든 장소가 들어오도록 범위를 맞춥니다.
2. 지도를 움직이고 확대·축소하며 둘러보기.
3. 장소 하나를 골라 **간단히 미리보기** → 이웃한 장소로 넘겨 보기 → **상세 열기**.
4. 검색 시작하기. 저장한 장소와 새 장소를 함께 찾는 검색 화면으로 이동합니다.
5. 필터로 좁히기.
   - 상태: 여러 개를 고를 수 있고, "전체"도 있습니다.
   - 종류: 하나만 고릅니다.
   - 필터가 걸려 있다는 사실이 늘 보여야 합니다.
6. 모음 하나만 지도에 보기. 리스트의 모음에서 들어오며, 현재 모음 이름과 장소 수를 보여 주고 해제할 수 있어야 합니다.
7. 내 위치로 이동하기.
8. "저장한 장소 전체 보기"로 돌아오기.
9. 장소 추가 시작하기. 이 앱의 가장 중요한 행동입니다.
10. 지도 ↔ 리스트 전환하기.
11. 설정 열기.
12. "확인 대기 링크 N개" 알아보기와 이어서 처리하기. 등록 도중 사람이 확인해야 하는 링크가 있을 때만 나타납니다.

## 4. 장소 미리보기와 상세

**미리보기**는 지도를 가리지 않는 가벼운 단계입니다. 다음을 보여 줍니다.

- 이름, 상태, 종류 또는 주소, 메모 앞부분, 저장한 사람, NEW 여부, 현재 보고 있는 순번(N / 전체).
- 이웃 장소로 넘기면 지도도 그 장소로 따라 움직입니다.
- 닫을 수 있습니다.

**상세**에서 할 수 있는 일은 다음과 같습니다.

- 상태 4종 바꾸기. 가장 자주 하는 편집입니다.
- 메모 쓰기와 저장.
  - 저장하지 않은 채 나가려 하면 확인합니다.
  - 상대와 충돌하면 상대의 현재 메모와 내 초안을 함께 보여 줍니다.
- 카카오맵에서 열기(길찾기 용도), 주소 복사.
- "지도에서 보기": 상세를 닫고 지도에서 그 장소를 보여 줍니다.
- 모음에 담기.
- 원본 인스타 보러 가기. 원본이 여러 개일 수 있습니다.
- 장소 삭제. 확인을 거치며, 삭제한 장소는 설정에서 복구할 수 있다고 안내합니다.
- 작은 위치 미리보기 지도.
- 저장 중·확인 중·재시도 상태를 표시합니다.

## 5. 집계(묶음) 표시 — 이번 재설계의 핵심 문제

### 현재 동작 (사실)

- 지도를 어느 정도 이상 축소하면 장소 이름표 대신 **숫자가 적힌 원**이 나옵니다.
  - 겹치는 장소 중 같은 행정구역에 있는 것끼리만 하나로 묶입니다.
  - 축소 정도에 따라 묶는 단위가 읍·면·동 → 구 → 시·군으로 커집니다.
- 장소가 **1곳뿐이어도** 축소 상태에서는 이름 대신 "1"이 적힌 원으로 나옵니다.
- 원 둘레의 진행 링은 "묶인 장소 중 다녀온 비율"입니다. 다녀옴·또 갈래·별로를 다녀온 것으로 계산합니다. 화면 어디에도 이 의미를 설명하지 않습니다.
- 원은 모두 같은 모양입니다. 상태 구성(가고 싶음 몇 곳 등)이나 NEW 여부가 드러나지 않습니다.
- 여러 곳이 묶인 원을 누르면 지도가 2단계 확대됩니다. 원하는 장소가 보일 때까지 여러 번 눌러야 할 수 있습니다.
- 1곳짜리 원을 누르면 바로 그 장소의 미리보기가 열립니다.
- 충분히 확대해야 이름표가 보입니다. 이름표에는 상태 표시와 24시간 NEW 표시가 붙습니다.

### 사용자 피드백

> 장소를 여러 개 등록하면서 집계핀을 써 봤는데 직관적이지 않다.

### 등록 직후에 생기는 일 (사실)

1. 저장을 마치면 지도로 돌아옵니다. 지도가 저장한 장소로 확대·이동하고 "장소를 저장했어요" 알림이 뜹니다.
2. 한 링크에서 **여러 곳**을 저장해도 지도는 **첫 번째 장소로만** 이동합니다. 나머지는 직접 찾아야 합니다.
3. 조금만 축소해도 새 장소는 숫자 원 안에 섞입니다. NEW 표시가 사라지고 어디에 들어갔는지 알 수 없습니다.
4. 상대가 저장한 새 장소(알림을 받고 앱을 연 경우)도 축소 상태에서는 구분되지 않습니다.

### 시안이 답해야 할 질문

- 숫자만 보고 "무엇이 몇 곳"인지 알 수 있나요? 1곳일 때도 숫자가 필요한가요?
- 묶음을 눌렀을 때 확대가 맞나요, 아니면 묶인 장소 목록을 보여 주는 게 맞나요? 둘 다라면 무엇을 기본으로 할까요?
- 상태(특히 가고 싶음 대 다녀옴)와 "새로 등록한 장소"가 축소 상태에서도 드러나야 하나요?
- 여러 곳을 한 번에 저장한 직후에는 그 장소들을 어떻게 보여 줄까요? (한꺼번에 범위 맞추기, 차례로 넘겨 보기 등)
- 이름표가 겹칠 때 묶음 대신 쓸 수 있는 방법이 있나요? (이름 생략, 우선순위로 일부만 이름 표시 등)
- 서울 전체 → 동네 → 가게 순으로 확대하는 동안 사용자가 같은 장소를 계속 따라갈 수 있나요?

### 성공 기준

- 처음 보는 사람이 설명 없이 축소된 지도에서 "어디에 몇 곳, 그중 가고 싶은 곳이 어디"인지 말할 수 있습니다.
- 축소 상태에서도 원하는 장소의 미리보기까지 **2번 이내**로 누를 수 있습니다.
- 여러 곳을 등록한 직후, 지도를 따로 움직이지 않고 새 장소 전부를 확인할 수 있습니다.
- 상대가 새로 넣은 장소를 알림 후 앱을 열었을 때 바로 찾을 수 있습니다.

## 6. 주요 시퀀스

각 시퀀스는 시안에서 화면 흐름(프레임 순서)으로 보여 줍니다.

- **S1 처음 열기:** 앱 열기 → 저장한 장소 전체가 보이는 지도. 장소가 0곳이면 첫 장소를 담도록 안내합니다.
- **S2 둘러보고 고르기:** 넓은 지역 → 확대하며 좁히기 → 장소 하나 미리보기 → 옆 장소로 넘겨 보기 → 상세.
- **S3 등록 후 돌아오기 (1곳):** + → (등록 화면, 범위 밖) → 저장 완료 → 지도에서 새 장소 확인 → 상태나 메모 바로 고치기.
- **S4 등록 후 돌아오기 (여러 곳):** 한 링크에서 3곳 저장 → 지도에서 3곳 모두 확인 → 그중 하나 상세.
- **S5 상대가 저장한 새 장소 확인:** 알림으로 앱 열기 → 새 장소 찾기 → 미리보기.
- **S6 필터:** 필터 열기 → 가고 싶음만 → 결과 지도 → 필터 걸림 표시 확인 → 해제.
- **S7 상세 편집:** 상태 바꾸기 → 메모 쓰기 → 저장 안 하고 나가려 하기(확인) → 저장.
- **S8 길찾기:** 미리보기 또는 상세 → 카카오맵 열기.

## 7. 반드시 그려야 하는 상태

- 불러오는 중, 불러오기 실패(다시 시도), 지도 자체 로드 실패(다시 시도 + 리스트로 보기).
- 장소 0곳 / 필터 결과 0곳(필터 초기화).
- 확인 대기 링크가 있을 때.
- 장소 미리보기와 확인 대기 표시, 알림 메시지가 동시에 있을 때 서로 가리지 않음.
- 상세에서 키보드가 열린 상태(메모 입력).
- 아주 긴 장소 이름, 메모가 긴 장소.
- 장소가 많은 지역(예: 한 동네 30곳)과 흩어진 지역(전국 몇 곳).

## 8. 시안 산출물

- 시퀀스별 프레임. 각 프레임에 세로 393×852, 가로 844×390을 기본으로 그립니다.
- 집계 표시 화면(S2·S4·S5)은 6개 크기를 모두 그립니다.
- 집계 표시는 **확대 단계별**(넓은 지역 / 구 / 동네 / 가게)로 같은 장소 묶음이 어떻게 바뀌는지 보여 줍니다.
- 시안마다 "기존 기능 목록 대비 누락 없음" 체크표와 "5장 질문에 대한 답"을 붙입니다.
