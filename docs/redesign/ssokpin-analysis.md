# 쏙핀 앱 분석 (2026-11-24)

- 대상: 쏙핀 2.0.0 (196), iPhone 앱을 Mac(Apple Silicon)에 설치해 1024×800 가로 창으로 직접 조작.
- 방법: 화면 캡처 + 클릭 자동화로 온보딩 → 로그인 → 약관 → 지도 홈 → 장소 상세 → 폴더 → 프로필 → 검색 순으로 탐색. 로그인·약관 동의는 사용자가 직접 진행.
- 캡처: `docs/design-references/ssokpin-2026-11-24/01–51.png` (git 제외 폴더, 로컬 전용). 34–51은 앱 안 추천 장소 2곳(ETF베이커리, 도량)을 "내 장소"에 저장한 뒤의 화면.
- 확인하지 못한 것: 실제 인스타그램 공유 → 저장 → 분석 완료 알림, 장소가 많을 때의 핀 클러스터, 초대 링크 흐름, 메모 작성·다녀왔어요(사진) 기록, 세로 iPhone 화면.

## 1. 한눈에

| 항목 | 쏙핀 | 데이트맵 현재 |
|---|---|---|
| 저장 진입 | 인스타 공유 시트 → 쏙핀 → 폴더 선택 | 공유 → 단축어/앱 → 후보·지점 확인 |
| 저장 시 확인 | 기본은 **확인 없음**, 백그라운드 분석 후 알림 | 저장 전 후보·지점 확인 |
| 폴더 이름 | "쏙" (기본 폴더 "내 장소") | 폴더 (기본 "내 장소", 1단계 진행 중) |
| 폴더 멤버 | 최대 10명, 별표로 주인 표시 | 기술 10명·운영 8명 계획 |
| 로그인 | 카카오·Google·Apple | 카카오·Google |
| 필수 약관 | 서비스·개인정보·**위치기반서비스** | 서비스·개인정보 (초안) |
| 지도 | 네이버 지도 | 카카오 지도 |
| 수익 | "광고 보고 개발자 응원하기" (보상형 광고로 추정) | 없음 |

## 2. 화면별 관찰

### 온보딩 (01–13)
- 가짜 인스타 게시물로 **공유 → 공유 대상… → 쏙핀 → 쏙 고르기**를 직접 눌러 보게 함. 하단에 단계 표시(공유 > 쏙핀 > 쏙 고르기).
- 공유 시트 아래 "쏙핀이 안 보이나요?" → **즐겨찾기 설정 5단계 연습**(더 보기 → 편집 모드 → 쏙핀 추가 → 맨 위로 이동 → 실제 적용). 이것도 가짜 공유 시트로 연습.
- 폴더를 고르면 "분석이 완료됐어요! '맛집'에 3건을 추가했어요" 알림 모형을 보여 줌 → 게시물 1개에서 여러 장소 추출.
- 요약 카드 3개: 게시글에서 공유 / 저장할 쏙만 고르면 끝 (앱 열 필요 없음) / 끝나면 알려 드려요.
- 가입 직전 "10초면 회원가입 완료!" 말풍선 + 하단 시트로 소셜 로그인 3종.

### 약관 (14)
- 필수 3개는 미리 체크, 선택(광고성 정보)은 꺼짐. "전체 동의 (선택 항목 포함)" 별도 행. 각 행 오른쪽 화살표로 본문 이동.

### 지도 홈 (15–19, 23–24)
- 상단: 전체 폭 검색창("장소, 쏙 검색") + 오른쪽 프로필 사진. 설정 버튼 없음(프로필이 설정 진입).
- 하단 시트 섹션: **내 쏙**(폴더 카드 가로 목록) / **내 주변 인기 장소** / **지금 뜨는 팝업·전시**(순위 번호 붙은 가로 카드) / 광고 응원 링크.
- 위치 권한이 없으면 "내 위치를 알려 주면…" + 위치 허용 버튼. 지도를 옮기면 **"을지로 인기 장소 · 지도 기준 · 1.5km"**처럼 지도 중심 기준으로 대체.
- 첫 진입 시 업데이트 안내 모달 → 알림 권한 요청 시트(나중에 가능)가 연달아 뜸.

### 장소 상세 (20–22)
- 제목 + "전시 · 진행 중" 상태 → 넓은 사진 → 버튼 3개(**길찾기**(주 버튼) / 지도 보기 / 저장하기) → 기간·장소명·주소(복사)·**Instagram 게시글 보러가기** 카드.
- 저장하기 → "쏙에 저장" 시트: 새 쏙 만들기 + 폴더 라디오 선택 + 비활성 상태의 "저장할 쏙을 골라 주세요" 버튼.

### 음식점 상세와 저장 이후 (36–45)
- 음식점 상세: 제목·카테고리·구 → 영업 상태 배지 → 사진 5장 넘김(1/5) → 버튼 3개(**길찾기** / **쏙에 저장** / **다녀왔어요**) → 영업시간(펼침) · 주소(복사) · 전화(복사) · 메뉴 3개 + 더보기 · **인스타그램 · 캐치테이블 외부 링크**. 오른쪽 위에 공유 버튼.
- 쏙에 저장 시트: 마지막에 쓴 폴더가 미리 체크됨, 버튼 문구가 "'내 장소'에 저장하기"로 바뀜. 누르면 버튼 안에 로딩 표시.
- 저장 후 같은 상세가 바로 바뀜: 제목 아래에 **폴더 칩(• 내 장소 >)**, "쏙에 저장" → **"쏙 변경"**, 맨 위에 **"메모를 남겨보세요 +"** 줄 추가, 하단 토스트 "ETF베이커리을(를) '내 장소'에 저장했어요"(조사 자동 처리 없음).
- 지역 표기가 저장 전 "성동구" → 저장 후 "성수동"으로 더 구체적으로 바뀜.
- 홈 추천 카드에도 저장한 장소는 오른쪽 위에 북마크 표시. 추천 섹션 제목은 지도를 옮기면 "을지로 → 관철동 인기 장소"처럼 동네 이름이 바뀜(옮긴 직후 한 번은 옛 이름이 남아 있었음).
- 관찰된 문제 1: 두 번째 장소(도량)는 저장된 뒤에도 상세가 "쏙에 저장" 상태로 남아 있었음(폴더에는 2개로 집계). 1회 관찰이라 재현 여부는 미확인.
- 관찰된 문제 2: **ETF베이커리의 주소는 성수동(성수이로16길 32)인데 지도 핀은 안국역 앞**에 찍힘. 홈 목록의 거리(을지로 기준 520m)도 핀 좌표를 따름 → 주소와 좌표의 출처가 다른 것으로 보임.

### 폴더 지도·목록 (47–51)
- 폴더 목록: 정렬(최신순) 옆에 **카테고리 칩이 저장된 장소로 자동 생성**(전체 / 카페·디저트 / 음식점). 행은 왼쪽 폴더 색 막대 + 사진 + 이름 + 아이콘·카테고리·동 + 영업 상태.
- 시트를 내리면 지도 위에 **폴더 색 원 + 이름** 핀, 하단에 폴더 이름·멤버 수·카테고리 칩만 남은 작은 시트.
- 핀을 누르면 지도가 그 장소로 이동하고 핀이 물방울 모양으로 바뀜, 하단에 이름·카테고리·동·영업 상태·폴더 칩 미리보기(공유·닫기).
- 카테고리 칩을 누르면 해당 장소들로 지도가 이동.

### 폴더 (25–28)
- 내 쏙 목록: "쏙 1개 · 장소 0곳", + / 닫기. 검색창 문구가 "내 쏙에서 검색"으로 바뀜.
- 폴더 안: 이름 옆 멤버 수 배지, 설명, 정렬(최신순), 빈 상태 안내("인스타그램·네이버 지도에서… 공유하고 담아 보세요").
- 더 보기 메뉴: 장소 정리 / 카테고리로 나누기 / 멤버 관리 / 쏙 수정하기 / 쏙 삭제하기(빨강).
- 멤버 관리: "멤버 1/10명", 초대 버튼.

### 프로필·설정 (29–31)
- 이름·이메일·로그인 수단 배지(KAKAO)·사진.
- 메뉴: 프로필 수정 / **저장 방식 설정** / 다녀온 곳 / 문의·건의 / FAQ / 평가하기 / 알림 / 마케팅 수신 / 약관 / 앱 버전. 하단에 로그아웃·회원탈퇴 버튼.
- **저장 방식 설정**: "바로 저장"(기본, 분석은 백그라운드) vs "확인하고 저장"(분석 결과를 보고 골라 저장).
- 다녀온 곳: 이번 달 N곳 / 쏙핀 사진 N장 요약 카드.

### 검색 (32–33)
- 폴더 안에서 검색하면 그 폴더 범위로만 검색("'내 장소'에서 검색"). 결과 없음 화면은 아이콘 + 검색어 인용.

## 3. 가로 모드 관찰 (데이트맵 필수 과제 참고)
- 대부분 화면이 1024px 폭 전체로 늘어남(검색창, 목록 행, 버튼). 별도 가로 레이아웃은 없음.
- **하단 시트형 선택 창(로그인, 쏙에 저장, 알림 요청, 더 보기 메뉴)은 가운데 약 490px 폭으로 제한** → 넓은 화면에서도 읽기 좋음.
- 장소 상세 사진이 가로로 늘어나 흐릿하고 잘림. 지도 영역이 시트에 가려 장소 핀이 보이지 않음.
- 마우스 휠은 시트가 아니라 지도에 먹음(시트는 드래그로만 펼쳐짐).

## 4. 데이트맵에 가져올 만한 것
1. **저장 방식 선택** — [장소 등록 재설계](../place-registration-redesign.md)의 핵심 질문(저장 시점 확인 vs 사후 확인)에 대한 실제 사례. 기본은 바로 저장, 원하면 확인 후 저장.
2. **공유 시트 연습 온보딩** — 단축어/공유 흐름이 어려운 데이트맵에 특히 유효. "앱이 안 보이나요?" 도움말도 같은 방식.
3. **위치 권한 없을 때 지도 중심 기준 추천** — 권한 거절 상태에서도 섹션이 비지 않음.
4. **시트형 선택 창 폭 제한** — 가로·태블릿에서 하단 시트를 가운데 고정 폭으로.
5. **폴더 맥락 검색** — 폴더 안에서는 그 폴더 범위로 검색.
6. **위치기반서비스 이용약관** — 데이트맵 `/consent` 초안에 필요한지 법률 검토 때 확인.
7. **저장 직후 상세가 그 자리에서 바뀜** — 폴더 칩·"쏙 변경"·메모 줄이 바로 나타나 저장됐다는 게 화면으로 보임.
8. **저장된 장소로 카테고리 칩 자동 생성** — 데이트맵 리스트·지도 필터에 참고.
9. **캐치테이블 링크** — 쏙핀은 음식점 상세에 캐치테이블 외부 링크를 표시함. 데이트맵의 "매장 확인 방법이 없어 보류" 상태와 비교할 사례(어떻게 매장을 연결하는지는 화면만으로는 알 수 없음).
10. **주의할 점** — 주소와 핀 좌표가 서로 다른 출처에서 오면 쏙핀처럼 어긋날 수 있음. 데이트맵의 네이버 정보(`PlaceExtras`)와 카카오 좌표를 합칠 때 같은 장소인지 확인 필요.

## 5. 다르게 갈 점
- 쏙핀은 첫 진입에 모달·권한 요청이 연속으로 뜸 → 데이트맵은 한 번에 하나만.
- 장소 상세에서 길찾기가 주 버튼 → 데이트맵은 상태(가고 싶음·또 갈래) 선택이 핵심이라 우선순위가 다름.
