- 캡처는 `docs/design-references/ssokpin-2026-11-24/`에 있습니다. 공개 저장소라 git에서 빠져 있고, 이 컴퓨터에만 있습니다.
- 본 화면은 다음과 같습니다.

| 화면 | iPhone 세로 | Mac 가로 창 |
| --- | --- | --- |
| 지도 홈 | `iphone-i26` | `15`–`19`, `23`, `24` |
| 방(쏙) 지도 | `i27`, `m38`, `m39`, `m40` | `47`–`51` |

- 쏙핀은 방을 **"쏙"**이라고 부릅니다. 아래에서는 우리 용어인 "방"으로 적습니다.

## 1. 화면 뼈대: 지도 + 바텀시트 하나

- **지도는 늘 화면 전체에 깔려 있습니다.** 그 위에 같은 바텀시트 **하나**가 내용만 바뀌며 올라옵니다.
  - 지도 홈: 내 방 목록 → 내 주변 인기 장소 → 지금 뜨는 팝업·전시
  - 방 하나: 방 이름 · 멤버 수 · ⋯ · X → 정렬 · 종류 칩 → 장소 목록
  - 장소 하나: 이름 · 공유 · X → 영업 칩 · 방 칩 → 사진 → 길찾기 · 쏙 변경 · 다녀왔어요 → 메모 · 영업시간 · 주소 · 메뉴
- **"지도 / 리스트" 탭이 없습니다.** 시트를 올리면 리스트가 되고(`m40`), 내리면 지도가 됩니다(`m39`). 이렇게 한 화면이 두 역할을 합니다.
- **시트 높이는 세 단계입니다.**
  - 접힘: 시트 머리만 보임(`48`, `50`)
  - 중간: 지도가 화면의 약 55%(`m39`, `i27`)
  - 끝까지: 지도가 거의 다 가려짐(`m40`)
- **위로 갈수록 좁은 범위입니다.** 전체 → 방 → 장소로 들어가고, 각 시트의 X를 누르면 한 단계 위로 돌아갑니다.
  - 방 시트의 X → 지도 홈
  - 장소 시트의 X → 방 목록
  - "뒤로"는 따로 없고 X 하나로 해결합니다.

## 2. 위쪽: 검색칸 + 프로필 하나

- 위에는 검색칸과 프로필 동그라미만 있습니다. 설정 · 방 바꾸기 · 필터 버튼이 없습니다.
- **검색칸 글자가 지금 범위를 알려 줍니다.**
  - 전체: "장소, 쏙 검색"
  - 방 안: "'내 장소'에서 검색", "'연남 카페 테스트'에서 검색"
  - 우리 앱의 "[방 이름]에서 검색"과 같은 방식입니다(2026-11-25에 적용).
- **방을 바꾸는 길은 시트에 있습니다.** 지도 홈 시트의 "내 쏙" 카드를 누르면 그 방으로 들어갑니다. 우리처럼 위쪽에 방 버튼을 두지 않습니다.

## 3. 핀과 묶음

- **방마다 색이 다릅니다.**
  - "내 장소"는 파랑, "연남 카페 테스트"는 빨강입니다(`m39`).
  - 방 이름 앞에도 같은 색 점이 붙습니다(`● 연남 카페 테스트`).
  - 장소 목록 줄 왼쪽에는 방 색 세로 띠가 있습니다(`m40`).
- **장소 하나 = 이름 없는 작은 색 원**(지름 약 16pt)입니다.
  - 확대해야 원 아래에 이름이 나옵니다(`48`–`51`: "도량", "ETF베이커리").
  - 많이 축소하면 원만 보입니다(`m39`의 "코코로카라" 원).
- **가까운 장소끼리는 숫자 원으로 묶습니다.**
  - 같은 방 색 원 안에 흰 숫자를 넣습니다(`m39`: 빨강 2 · 3, `i26`: 전국 화면 서울 위 파랑 2).
  - 지역 이름이나 카드는 쓰지 않습니다. 같은 모양의 원이 크기만 조금 커집니다.
- **고른 장소는 물방울 핀으로 바뀝니다.**
  - 장소를 누르면 그 장소만 파란 물방울 핀이 되고, 아래에 이름이 붙습니다(`i28`: "라무라 성수").
  - 지도는 그 장소로 이동하고 크게 확대합니다(축척 50m).
- 지도는 네이버 지도이고, 네이버 기본 가게 아이콘(주황 · 보라)이 그대로 보입니다. 그래서 우리 핀과 가게 아이콘이 섞여 보입니다.

## 4. 지도 위 버튼과 알림

- 지도 위 버튼은 **오른쪽 아래 내 위치 하나**뿐입니다. 회색 반투명 원으로, 시트 바로 위에 붙어 시트를 따라 오르내립니다.
  - 전체 보기 · 확대/축소 · + 버튼이 없습니다.
  - 장소 추가는 인스타 공유로만 들어온다고 보고 지도에 + 를 두지 않았습니다.
- **저장 알림은 지도 위 칩으로 쌓입니다.**
  - "'내 장소'에 1건을 추가했어요"처럼 방 색 체크가 붙은 흰 알약 칩입니다.
  - 여러 개면 위로 쌓이고, "× 모두 닫기"가 붙습니다(`m38`).
  - 사라지는 토스트가 아니라 지도에 남는 알림이라서, 공유한 뒤 앱을 열면 무엇이 들어왔는지 바로 보입니다.
- 축척 막대와 NAVER 로고가 시트 바로 위 왼쪽에 붙습니다.

## 5. 방 시트 · 장소 시트 안

- **방 시트**(`i27`, `m40`)
  - 머리: 색 점 · 방 이름 · 사람 아이콘 + 멤버 수 · ⋯(동그라미) · X(동그라미)
  - 그 아래: "최신순 ▾" 정렬, 종류 칩(전체 · 음식점 · 놀거리·쇼핑)
  - 종류는 저장한 장소에서 자동으로 만듭니다. 칩을 누르면 지도도 그 장소들에 맞춰 움직입니다(`51`).
  - 방금 저장한 묶음은 "✦ 방금 추가한 6건" 파란 글자로 맨 위에 모아 보여 줍니다.
  - 목록 줄: 사진 · 이름 · 거리(오른쪽 위) / 분류 아이콘 + 분류 · 동 / 영업 상태 · 시간
  - 우리 B안 리스트 줄과 거의 같은 구성입니다. 다른 점은 줄 왼쪽의 방 색 띠뿐입니다. 우리는 이 띠를 빼기로 했습니다.
- **장소 시트**(`i28`, `p07`)
  - 순서: 이름 → 분류 · 동 · 거리 → 영업 칩 · 방 칩(›) → 사진(1/5) → 할 일 줄 → 메모 → 영업시간 → 주소(복사) → 메뉴
  - 할 일 줄: 파란 알약 "길찾기"(주 버튼) · 흰 "쏙 변경" · 흰 "다녀왔어요"
  - 길찾기를 누르면 네이버 · 구글 · Apple 지도 중에서 고르는 시트가 뜹니다(`q09`).
  - 우리가 2026-11-26에 정한 장소 상세(이름 → 칩 → 사진 → 할 일 → 메모 → 정보)와 순서가 같습니다.

## 6. 데이트맵과 비교

| 항목 | 쏙핀 | 데이트맵 지금 |
| --- | --- | --- |
| 지도/리스트 | 시트 하나를 올리고 내림, 탭 없음 | 아래 지도 · 리스트 탭 + 따로 된 리스트 화면 |
| 범위 바꾸기 | 지도 홈 시트의 방 카드 | 위쪽 방 버튼 → 내 방 시트 |
| 묶음 표시 | 방 색 숫자 원(이름 없음) | 지역 카드(도 · 시 · 구 · 동 이름 + 수) |
| 낱개 핀 | 이름 없는 색 원 → 확대하면 이름 | 이름 핀(점 없음, 2026-11-26) |
| 고른 핀 | 물방울 핀 + 크게 확대 | 미리보기 카드 + 핀 강조 |
| 지도 위 버튼 | 내 위치 하나 | 전체 보기 · 내 위치 · + |
| 저장 알림 | 지도 위에 쌓이는 칩 + 모두 닫기 | 사라지는 토스트 + 새 장소 시트(NEW) |
| 방 색 | 핀 · 점 · 목록 띠 모두 방 색 | 전체 보기에서만 핀 색 · 방 머리띠 |

## 7. 가져올 만한 것 (결정용 번호)

1. **방 색 숫자 원 묶음.** 장소가 몇 개 안 되는 지역에서 우리 지역 카드는 너무 큽니다. 3차 점검 18번의 "1" 카드 문제도 이것으로 풀립니다. 확대한 단계(동 · 거리 수준)에서 쓰기 좋습니다.
2. **저장 알림을 지도 위 칩으로 남기기.** 인스타 공유로 저장한 뒤 앱을 열었을 때 무엇이 들어왔는지 바로 보입니다. 지금의 "새 장소" 시트와 NEW 배지를 더 가볍게 바꿀 수 있습니다.
3. **"방금 추가한 N건" 묶음을 리스트 맨 위에.** 우리 "방금 담은 N곳" 시트와 같은 내용을 리스트 안에 둡니다.
4. **장소를 고르면 물방울 핀 + 크게 확대.** 지금 고른 장소가 지도에서 분명히 보입니다.
5. **길찾기 앱 고르기.** 네이버 · 카카오 · Apple 지도 중에서 고릅니다.
6. **방 시트 X 하나로 위 단계 가기.** 3차 점검의 "뒤로 가기가 일정하지 않음"과 연결됩니다.

## 8. 그대로 두는 게 나은 것

- **지도/리스트 탭을 없애는 것**은 사용자가 하단 탭과 + 버튼을 그대로 두기로 정했으므로 하지 않습니다(메모리: 지도 도구 유지).
- **넓은 범위의 지역 카드**(도 · 시 단계)는 우리가 장소 수 · 이름을 한눈에 보여 주는 장점이 있습니다. 쏙핀의 원은 전국 화면에서 숫자만 있어 어디인지 읽기 어렵습니다(`i26`).
- **쏙핀의 다른 방 핀 색이 파랑**이라 네이버 지도의 파란 아이콘과 헷갈립니다. 우리 방 색 10가지 원단 색이 더 잘 구분됩니다.

## 9. 캡처로 확인하지 못한 것

- 장소가 수십 개일 때 묶음이 어떻게 나뉘고 합쳐지는지(확대 단계별 경계)
- 여러 방을 한 지도에 같이 보는 화면이 있는지. 지도 홈에서는 핀이 "내 장소" 것만 보였습니다(`i26`).
- 핀끼리 겹칠 때 처리, 지도를 움직이면 목록이 바뀌는지
- 시트 높이를 바꿀 때 지도 중심이 어떻게 움직이는지(동작은 캡처로 볼 수 없음)

이 네 가지는 실제 iPhone에서 핀을 많이 넣은 방을 축소 · 확대하며 녹화하거나 캡처해야 확인할 수 있습니다.
