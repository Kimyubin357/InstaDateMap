# 레퍼런스로 바꾼 화면 기록

사용자가 다른 앱 화면을 레퍼런스로 주고 "이렇게 바꿔줘"라고 한 화면을 모두 여기에 기록합니다. 새 레퍼런스로 화면을 바꿀 때마다 표에 한 줄, 아래에 한 절을 추가합니다.

- **레퍼런스 이미지**는 `docs/design-references/`에 날짜-화면 이름으로 저장합니다. 이 저장소가 **공개(PUBLIC)** 이고 다른 앱 화면과 개인 정보(프로필 사진·이름)가 들어 있어서 이 폴더는 `.gitignore`로 **로컬에만** 둡니다. 다른 컴퓨터에서는 이미지가 없으므로 아래 "레퍼런스 요약"을 기준으로 봅니다.
- 레퍼런스 4장의 공통 구조는 [단순 구조 규칙](redesign/simple-structure-rules.md)으로 정리했습니다. 이 규칙은 **사용자가 특정 화면의 리디자인을 요청했을 때만** 적용합니다.
- 레퍼런스의 **배치·순서·문구**는 따르고, **색·서체·원단·점선 같은 앱 테마**는 [디자인 철칙](design-principles.md)을 유지하는 것이 지금까지의 원칙입니다. 테마까지 레퍼런스처럼 바꾸기로 하면 이 원칙과 철칙을 함께 고칩니다.

## 반복해서 나타나는 레퍼런스 경향

지금까지 받은 레퍼런스 4장(로그인·약관 동의·약관 보기·프로필 수정)은 모두 같은 방향입니다. 전체 UI 방향을 정할 때 참고합니다.

- 흰색·연회색 단색 바탕, 질감·점선 없음
- 고딕 계열 시스템 서체(굵은 제목, 보통 본문)
- 가운데 정렬 제목의 얇은 머리글, 왼쪽 `<` 뒤로 가기
- 화면 아래 폭 전체의 둥근 큰 버튼(비활성은 회색)
- 열린 목록 행 + 오른쪽 `>` 화살표, 얇은 회색 구분선
- 포인트 색은 한 가지(파란색)만 작게 사용

데이트맵은 지금 아이보리 원단·손글씨체(박다현체)·붉은/초록 잉크·점선 테마입니다. 레퍼런스의 배치만 가져와 왔기 때문에, 화면마다 "구성은 레퍼런스, 느낌은 원단"이 섞여 있습니다.

## 화면별 기록

### 2026-11-07 지도 홈 — 직방·다방 비교

- 레퍼런스 요약: 부동산 지도 앱의 지역 묶음 카드(지역명 + 개수), 확대 단계별 도·시·구·동 묶음.
- 따른 것: 숫자 원 → 지역 카드(지역명·가고 싶음 수·NEW·다녀온 비율 바), 도 13–14 / 시 10–12 / 구 7–9 / 동 4–6 단계.
- 유지한 것: 내 위치·전체 보기·하단 탭·+ 버튼(사용자 확정), 원단 테마.
- 자세한 비교: [map-home-compare.md](redesign/map-home-compare.md)

### 2026-11-24 로그인

- 레퍼런스 요약: 흰 바탕 가운데 캐릭터 그림, 굵은 환영 문구 두 줄 + 회색 부제, 아래에 카카오(노랑)·구글(흰색 테두리)·애플(검정) "○○로 시작하기" 버튼.
- 따른 것: 그림 → 환영 문구 → 부제 → 하단 버튼 순서, "카카오로 시작하기 / 구글로 시작하기" 문구, 카카오·구글 공식 버튼 색.
- 다른 것: 애플 로그인 없음(나중에), 바탕·서체는 원단·박다현체, 그림은 앱 캐릭터. 하단에 이용약관·개인정보 처리방침 링크 추가. 짧은 가로는 왼쪽 인사 / 오른쪽 버튼 두 칸.

### 2026-11-24 약관 동의

- 레퍼런스 요약: 머리글 "약관 동의", 지도 아이콘 + "이용을 위해 서비스 약관 동의가 필요해요", 테두리 상자의 "전체 동의 (선택 항목 포함)", [필수] 3개·[선택] 1개 체크 행과 `>`, 아래 "동의하고 시작하기!"(비활성 회색).
- 따른 것: 구성·문구·항목 순서(서비스 → 개인정보 → 위치 → 광고성 정보), 필수 3개 전부 체크 시 버튼 활성, `>`로 전문 보기.
- 다른 것: [필수]는 초록·[선택]은 연한 잉크색(레퍼런스는 파랑/회색), 원단 상자·점선, 짧은 화면은 아이콘을 숨기고 짧은 가로는 왼쪽 안내 / 오른쪽 목록.

### 2026-11-24 약관 보기(목록)

- 레퍼런스 요약: 머리글 "약관 보기", 약관 4개를 "이름 (필수/선택)" 한 줄씩 나열하고 오른쪽 `>`, 행 사이 구분선.
- 따른 것: 설정의 약관 링크 3개를 "약관 보기" 한 줄로 모으고, 목록 화면에서 약관 4개를 (필수)/(선택)과 함께 표시. 각 약관의 뒤로 가기는 목록으로.
- 다른 것: 순서는 동의 화면과 같게(레퍼런스는 가나다순), 설정과 같은 원단 행·점선 구분선·목록 아이콘.

### 2026-11-24 프로필 수정

- 레퍼런스 요약: 머리글 "프로필 수정", 가운데 큰 원형 사진 + 오른쪽 아래 파란 카메라 표시, "사진을 탭해서 변경", "닉네임" 라벨과 입력칸, 화면 맨 아래 폭 전체 "저장"(비활성 회색).
- 따른 것: 배치·문구 그대로. 사진을 탭하면 아래에서 선택 창(앨범에서 선택 / 카카오·구글 사진으로 / 사진 없이 / 취소)이 열립니다. 이전의 "카카오 사진·사진 올리기·사진 없이" 버튼 줄은 없앴습니다.
- 다른 것: 카메라 표시는 초록 잉크 원, 입력칸은 크림 원단·점선, 저장은 붉은 잉크 버튼. 닉네임 아래에 "폴더 멤버에게 이 이름으로 보여요" 안내와 "카카오 이름으로 바꾸기"를 유지. 짧은 가로는 왼쪽 사진 / 오른쪽 닉네임·저장.
- 확인: 필수 5개 크기와 393×852·1440×900에서 가로 넘침 0, 불필요한 세로 스크롤 0, 세로·데스크톱은 저장 버튼이 화면 아래 16px, 사진 선택 창 열기·선택 반영(저장하지 않음)을 확인했습니다.
