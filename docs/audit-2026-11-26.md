# 화면 점검 3차 (2026-11-26)

## 범위와 방법

**시뮬레이터에서 직접 눌러 본 곳** (iPhone 17 시뮬레이터, 로컬 앱 + 운영 데이터)

- 지도: 방 하나 보기 · 전체 보기, 지역 카드, 미리보기, 지도에서 연 상세(접힘·중간·끝까지)
- 리스트: 전체 장소 · 방 카드, 방 안 장소(선택 모드 · 종류 시트 · 정렬), 모음 탭(밀어서 삭제 · 편집 시트)
- 검색, 장소 추가 · 저장할 방 시트
- 설정과 하위 화면 전부: 방 목록, 방 ⚙ 시트, 방 수정 · 멤버 관리 · 멤버 ⋯ 시트, 알림, 프로필, 삭제한 장소, 약관 목록 · 본문
- 잘못된 초대 링크, 없는 주소(404)

**코드만 읽은 곳** (하위 에이전트 4개가 파일을 읽어 확인)

- 등록 흐름 전체: 분석, 확인 대기, 지점 고르기, 방금 담은 N곳
- 방 · 모음 · 초대 · 멤버
- 로그인 · 약관 동의 · 탈퇴 · 알림 · 세션 만료
- 쓰지 않는 코드 · 파일 · 문서

**하지 않은 것**

- 저장 · 삭제 · 옮기기 · 나가기 · 탈퇴는 운영 DB라 확인 창까지만 봤습니다.
- 실기기, 가로 모드, 위치 권한을 허락한 상태는 확인하지 않았습니다.

**표시와 번호**

- "추정"은 코드 흐름으로 판단하고 실제로 재현하지 않은 항목입니다.
- 번호는 결정하실 때 부르기 쉽게 붙였습니다.
- 지난 점검([2차](audit-2026-11-25-round2.md))에 있던 항목은 "2차 n번"으로 표시했습니다.

## 먼저 고칠 것 (사용자가 막히는 고장)

1. **[낮음 · 정정] 권한이 없어 거절되면 로그아웃될 수 있음.**
   - 처음 점검에서는 [높음]으로 적었지만 과장이었습니다. 사용자가 직접 해 봤을 때 로그아웃되지 않았습니다.
   - 이유: 화면이 처음 등록한 사람에게만 삭제·옮기기 버튼을 보여 주고, 리스트에서 밀어 지울 때도 서버에 보내기 전에 막습니다(`PlaceSheet.tsx:41,221`, `CollectionsList.tsx:225`).
   - 남은 경우: 이 기기의 멤버 정보가 오래돼 버튼이 잘못 보일 때만 서버가 409를 돌려주고, 상세 화면이 `lock()`을 부릅니다(`PlaceSheet.tsx:58,143`). 드문 경우라 낮음으로 내립니다.
2. **[높음 · 추정] 방에서 내보내지거나 보던 방이 지워지면, 눌리지 않는 로그인 화면에서 멈춤.**
   - 흐름: sync가 `expired`를 보내면 `lock()`이 `/login`으로 보냅니다. 하지만 아직 로그인된 상태라 서버가 바로 다른 화면으로 되돌립니다(`login/page.tsx:11`).
   - 문제: 잠금 화면은 주소가 `/login`일 때만 풀리므로(`BoardProvider.tsx:51`) 그대로 남습니다. 앱을 다시 켜야 풀립니다.
   - "방에서 나가게 됐어요" 같은 안내도 없습니다.
3. **[중간 · 고침 2026-11-26] 서버 오류가 "인스타 링크를 확인해 주세요"로 보임.**
   - 링크가 맞아도 DB 오류나 500·503이 나면 모두 `not_instagram`으로 분류합니다(`registration.ts:105`).
   - 화면에는 "다른 링크 넣기" 버튼 하나뿐이고, 다시 시도할 길이 없습니다.
   - 고친 내용: 서버가 진짜 링크 오류에만 `not_instagram` 코드를 붙이고, 그 밖의 분석 전 실패와 연결 끊김은 새 "서버에 잠시 문제가 생겼어요" 화면(다시 시도 · 지도로)으로 보냅니다. "삭제한 장소에 있는 링크"도 따로 안내하고 삭제한 장소로 가는 버튼을 둡니다(`registration.ts` `addFailure`, `pipeline.ts`, `AddForm.tsx`).
4. **[중간] 닫을 수 없는 창.**
   - "장소를 찾을 수 없어요" 창(`MapApp.tsx:413`)에는 X도 버튼도 없습니다. 옮겨지거나 지워진 장소의 알림을 누르면 이 창이 뜹니다.
   - 확인 대기 창과 종류 시트에도 X가 없습니다.
5. **[중간] 전체 보기에서는 확인 대기가 지금 연 방 것만 보임.**
   - 다른 방의 확인 대기는 그 방에 들어가야만 보입니다.
   - 그 링크를 `/confirm/…`으로 열면 "링크를 찾을 수 없어요"가 뜹니다(`MapApp.tsx:45,383`, `confirm/[sourceId]/page.tsx:12`).
6. **[중간] 초대로 참여하면 그 방이 아니라 '전체'로 열림 (추정).**
   - 참여한 뒤 `/`로만 이동하고, 범위를 바꾸지 않습니다(`InviteScreen.tsx:21-24`).
   - 설정 → 방에서 '보는 중'인 방을 눌러도 범위가 그대로라 전체가 열립니다(`FoldersPanel.tsx:130`).
7. **[중간] 방이 0개면 설정에 갈 수 없어 로그아웃 · 탈퇴를 못 함.**
   - `/settings`는 `/folders`로 보내는데, 방 0개 화면에는 뒤로 버튼이 없습니다(`access.ts:31`, `FoldersPanel.tsx:188`).
8. **[중간] 방 설정에서 바꾼 내용이 다른 화면에 늦게 보임.**
   - 이름 · 색 저장, 내보내기, 방장 넘기기, 삭제 뒤에 방 목록을 새로 받지 않습니다(`notifyBoardChange:false`).
   - 그래서 내 방 시트 · 머리띠에 옛 이름 · 인원이 남습니다. 지운 방 카드를 누르면 "참여한 방만 열 수 있어요"가 뜹니다.
9. **[중간] 모음 검색어가 남아 목록이 숨은 채로 굳음.**
   - 모음이 5개일 때 검색해 둔 상태에서 4개로 줄면, 검색칸은 사라지고 걸러진 목록만 남습니다(`CollectionsList.tsx:259,262`).
10. **[중간] 다시 동의할 때 광고 수신 동의가 조용히 꺼짐.**
    - 약관 버전이 바뀌어 다시 동의하면, 광고(선택) 칸이 꺼진 채로 시작해 그 값으로 덮어씁니다(`ConsentScreen.tsx:11`, `015_terms.sql:30`).
    - 화면에 "약관이 바뀌었어요" 안내도 없습니다.
    - 뒤로 버튼은 확인 없이 바로 로그아웃합니다.
11. **[중간] 알림 설정이 막다른 길.**
    - 방 ⚙ 시트의 "이 방 알림"을 누르면 알림 설정으로 가는데, 홈 화면 앱이 아니면 방별 알림 줄이 아예 안 보입니다.
    - 어느 방인지도 표시되지 않습니다(시뮬레이터 사파리에서 확인).
    - 같은 화면에서 위 줄은 "홈 화면에 추가한 앱에서 열어 주세요", 아래 줄은 "아직 켤 수 없어요"라고 안내합니다.
12. **[중간] 90일이 지나면 알림이 조용히 끊김.**
    - 로그인은 처음 날짜부터 90일 고정이라, 매일 써도 늘어나지 않습니다(`access.ts:9`).
    - 만료되면 알림이 오지 않습니다. 다시 로그인하면 구독이 지워지고, 다시 켜 달라는 안내도 없습니다.

12-1. **[높음 · 고침 2026-11-26] 친구 초대(방 설정)에 갔다가 뒤로 오면 "장소를 불러오지 못했어요"에서 멈춤.**
   - 재현: 방을 바꾼 뒤 방 ⚙ → 초대하기·멤버 관리로 가서 뒤로 가기. 지도에는 오류 창, 리스트에는 "장소 응답을 확인하지 못했어요 · 다시 불러오기"가 뜨고, 다시 불러오기를 눌러도 같은 오류가 반복됩니다.
   - 원인: 뒤로 가기가 예전에 받아 둔 `/` 화면을 되살리면서 **바꾸기 전 방의 입장 정보**를 다시 넣습니다. 서버는 이미 새 방을 보고 있어서, 장소 응답의 방이 계속 맞지 않습니다(`board-store.ts`의 방·버전 비교).
   - 고친 내용: 응답의 방이 다르면 오류로 막지 않고, 서버에서 지금 입장 정보를 한 번 다시 받아 맞춥니다(`onStaleAccess` → `resetAccess`). 같은 정보로 또 어긋나면 그때 오류를 보여 줍니다(무한 반복 방지). 시뮬레이터에서 같은 흐름이 정상으로 돌아오는 것을 확인했습니다.
12-2. **[낮음] 초대하기를 누를 때마다 초대 링크가 새로 생김.** 멤버 관리 화면에 "쓸 수 있는 링크 5개"처럼 쌓입니다. 서버는 링크 원문을 저장하지 않아 이미 만든 링크를 다시 보여 줄 수 없기 때문입니다. 링크 하나만 쓰려면 다시 만들 때 예전 링크를 끊을지 정해야 합니다.

## 디자인 통일성

### 버튼 색 (규칙: 만들기 · 저장 · 진행은 초록, 빨강은 지우기 · 위험)

13. **아직 빨강인 긍정 버튼.** 이렇게 많아서 한 번에 바꿀지 정해야 합니다.
    - 장소 추가: "장소 찾기"(시뮬레이터에서 봄), "다시 시도" · "다른 링크 넣기" 등(`AddForm.tsx`)
    - 확인 대기: "‘방’에 N곳 담기"(`ConfirmForm.tsx:198`)
    - 직접 찾기: "‘방’에 담기", "N번으로 고르기"
    - 검색: "이 방에 저장"
    - 옮기기 시트: "옮기기"
    - 모음: "N곳 담기" · "장소 골라 담기"
    - 초대: "참여하기"
    - 새 장소 시트: "지도에서 보기"
    - 종류 시트: "장소 보기"
    - 프로필: "저장"
    - 약관 동의: "동의하고 시작하기"
    - 삭제한 장소: "되돌리기"
    - 지도 오류 창: "다시 시도"
    - 확인 창(ActionDialog): 위험하지 않은 확인도 모두 빨강
14. **색 뜻이 뒤집힌 곳: 삭제한 장소.** "되돌리기"는 빨강이고, "기록에서 지우기"는 흰 버튼입니다.
15. **남겨 둘지 정할 것.** 길찾기(빨강 알약)와 + 버튼(빨강)은 지난번에 판단을 미뤘습니다.
16. **[docs/design-principles.md](design-principles.md) 1절 · 8절**은 아직 "주요 실행은 붉은 잉크"라고 씁니다. 새 규칙으로 고쳐야 합니다.

### 같은 것이 다른 모양

17. **방을 고르는 화면이 네 가지 모양입니다** (2차 8번에서 하나 늘었습니다).
    - 내 방 시트: 색 카드 + 얼굴
    - 저장할 방 시트: 색 막대 + **초록** 체크
    - 설정 → 방: 색 막대 + 맨 톱니
    - 장소 추가 머리: 빨간 점선 카드 + 알약 "바꾸기"
    - 체크 색도 섞여 있습니다: 내 방 시트는 빨강, 저장할 방 시트는 초록.
18. **방 안 지도와 전체 지도의 지역 카드 규칙이 다릅니다.**
    - 방 안 지도: 장소가 1곳뿐인 지역은 이름 없이 "1"만 나옵니다(부산 · 제주).
    - 전체 지도: 같은 경우에도 "부산 1"처럼 이름이 나옵니다.
19. **장소 정보가 화면마다 다릅니다.**
    - 리스트 줄: 사진 · 영업시간 · 얼굴
    - 지도 미리보기 카드: 이름 · 분류 · 사람 아이콘만 있고 가운데가 비어 있음
    - 검색 결과: 점선 동그라미 분류 아이콘 + 빨간 "저장됨" + ›
    - 삭제한 장소: 사진 없음, 실선
20. **닫기 · 취소 글자 색이 다릅니다.** 검색 "취소"는 빨강이고, 리스트 선택 "취소"와 편집 · 선택은 초록입니다.
21. **선택 모드의 고르기 표시가 "+" 점선 칸입니다.** 사진이 사라지면서 '추가'처럼 보입니다. 체크 상자가 자연스럽습니다.
22. **시트 머리가 다릅니다.** 종류 시트에는 X와 손잡이가 없습니다. 제목 "어떤 종류를 볼까요?" 아래에 "장소 종류"가 한 번 더 있습니다.
23. **오류 화면이 두 모양입니다.**
    - 잘못된 초대: 큰 초록 타일 + 흰 "내 지도 열기"
    - 404: 점선 카드 + 빨간 "지도 열기"
    - 404 아이콘이 초대와 같은 링크 아이콘입니다.
24. **하위 화면 머리가 다릅니다.**
    - 삭제한 장소와 약관 본문에는 `settings-page` 클래스가 없습니다.
    - 약관 동의 화면 머리는 22px 갈색이고, 다른 화면은 28px 빨강입니다.
    - 약관 목록은 첫 줄 위 선과 묶음 제목이 없습니다.
25. **입력칸 모양이 다릅니다.**
    - 프로필 이름칸: 점선, 글자 수 표시 없음
    - 모음 · 방 이름칸: 실선, 0/40처럼 글자 수 표시
    - 프로필은 "닉네임", 설정은 "이름"이라 부릅니다.
26. **시스템 메뉴가 섞여 있습니다.** 정렬(최근 저장순 / 가까운순)만 iOS 기본 메뉴(시스템 글꼴)입니다. 첫 탭에 안 열리고 두 번째 탭에 열렸습니다.

### 아이콘 · 문구

27. **아이콘 뜻이 섞여 있습니다.**
    - 설정 "방 바꾸기·관리"는 지도 아이콘인데, 방 버튼은 네 칸 아이콘입니다.
    - 약관 · 모음 안내 · 광고 동의 내용은 리스트 탭과 같은 list 아이콘입니다.
    - "사용법 다시 보기"는 새로고침 아이콘입니다.
    - 시계 아이콘을 영업시간 · 네이버 예약 · 오류 안내에 같이 씁니다.
    - 확인 창 아이콘: 나가기는 X, 내보내기는 휴지통, 방장 넘기기는 핀, 모음에서 빼기는 체크입니다.
28. **로그아웃 줄에 ›가 붙어 있습니다.** 화면 이동이 아니라 확인 창이 뜹니다.
29. **"삭제한 장소"가 설정 맨 아래**(약관 다음)에 있어 찾기 어렵습니다.
30. **화면에서 뺀 "상태"가 문구에 남아 있습니다.**
    - 삭제한 장소 안내: "메모·상태·원본 링크"
    - 이용약관 제2조 "콘텐츠"
31. **옛 용어가 화면에 나올 수 있습니다.**
    - DB 문구 "이 보드의 저장자가 아닙니다"와 "이 지도는 더 이상 멤버를 받을 수 없어요": `roomWord`는 "폴더"만 바꿉니다.
    - "폴더를 만든 사람만…"은 "방을 만든 사람만…"으로 바뀌어 보입니다. 방장을 넘긴 뒤에는 "방장만"이 맞습니다.
    - "입장 정보", "사용할 이름을 먼저 골라 주세요"(PIN 시절)
    - 알림 기본 제목 "우리 지도에…"
    - 로그인 부제 "SNS에서 발견한": 인스타만 받기로 했습니다.
32. **표기가 섞여 있습니다.**
    - 날짜: "2026. 11. 9." / "10월 31일"
    - 장소 수: "장소 52" / "장소 52곳"
    - 인원: "나만" / "혼자"
    - 문장: "우리 방 방이 비어 있어요"(방 이름 뒤에 "방"이 또 붙음)
33. **종류 이름이 카카오 원문 그대로입니다.** "관광,명소"처럼 쉼표 뒤 띄어쓰기가 없습니다. 의류판매 · 음악 · 즉석사진처럼 잘게 쪼개진 종류가 15개 넘습니다.
34. **종류 시트의 "장소 보기"는 닫기 역할만 합니다.** 종류를 누르는 순간 리스트가 이미 바뀝니다.

## 작은 엣지 케이스

35. **'방금 담은 N곳 → 옮기기'가 묶음째 실패할 수 있습니다 (추정).** 남이 등록한 기존 가게가 하나만 섞여도 전체를 거절합니다(`022_move_places.sql:27`).
36. **저장하지 않고 나가도 방이 바뀝니다.** /add에서 방을 [바꾸기]만 해도 기기의 열린 방이 바뀌어, 그냥 나가도 지도가 그 방을 보여 줍니다.
    - 시트의 "새 방 만들기"는 방 목록으로 가서 입력한 링크가 사라집니다. 방 10개가 찼을 때도 눌립니다.
    - 옮기기 시트의 "새 방 만들기"도 방 목록으로 갑니다.
37. **가게 정보 "다시"가 5분 동안 듣지 않습니다 (추정).** 오류 응답도 5분 동안 캐시됩니다(`details/route.ts:18`).
38. **전체 보기 검색에서 다른 방에 있는 가게를 지금 방에 담을 수 없습니다.** 저장 버튼이 나오지 않습니다(`place-search.ts:22-24`).
39. **여러 방에 있는 같은 가게의 상세가 대표 방 하나 기준입니다 (추정).** 메모 · 삭제가 그 방에만 적용되고, "이 방에서 빠져요"라고만 해서 어느 방인지 모릅니다.
40. **옮기기가 "새 장소를 담았어요" 알림을 보냅니다 (추정).**
41. **모음 관련.**
    - 아무 멤버나 밀어서 지울 수 있고, 되돌리기가 없습니다. 장소는 처음 등록한 사람만 지웁니다 → 정책을 정해야 합니다.
    - 이름이 겹치면 저장한 뒤에야 알려 줍니다.
    - 다른 멤버가 바꿔도 "다른 기기에서 바뀌었어요"라고 나옵니다.
42. **선택은 200곳까지, 옮기기는 100곳까지입니다.** 101곳 이상 고르면 옮기기에서 오류가 납니다.
43. **얼굴 사진을 이름으로 찾습니다 (추정).** 다른 방에 같은 이름의 다른 사람이 있으면 엉뚱한 얼굴이 붙습니다.
44. **뒤로 가기가 일정하지 않습니다.**
    - `?new=1`에서 뒤로 가면 방 목록으로 갑니다.
    - ⚙ 시트로 와서 삭제하면 주소에 `?room=`이 남고, 새로고침하면 "방을 찾을 수 없어요"가 뜹니다.
45. **초대 미리보기가 '방 10개 상한'을 확인하지 않습니다.** "참여하기"를 누른 뒤에야 오류가 납니다.
46. **긴 방 이름(30자)과 이름(20자)이 설정 줄 밖으로 넘칠 수 있습니다 (추정, `fabric-theme.css:304`).**
47. **카카오톡 안 브라우저에서 구글 로그인이 막힙니다 (추정).** 초대 링크는 주로 카톡에서 열립니다.
48. **기타.**
    - 프로필 사진 주소가 깨지면 깨진 이미지가 그대로 보입니다.
    - 오프라인으로 열면 브라우저 기본 오류 화면이 뜹니다.
    - 탈퇴 확인 창에 "방장 자리가 넘어가요"라는 안내가 없습니다.
    - 위치 권한을 거부해도 "위치를 확인하지 못했어요"만 나옵니다.
