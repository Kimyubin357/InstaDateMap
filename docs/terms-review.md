## 3. 전문가 검토가 필요한 남은 위험

1. **서버 지역**: 2026-11-24 확인 당시 Supabase는 시드니, Vercel 함수는 미국 동부였습니다. 둘 다 서울로 옮기기로 하여([이전 절차](supabase-seoul-move.md)) 처리방침 5항을 서울 기준으로 고쳤습니다. 해외 전송은 Google(Gemini)과 웹 푸시 전달 사업자만 남습니다. **이전을 마친 뒤 약관 변경을 배포해야** 처리방침이 실제와 맞습니다. 장소 추출에 Anthropic을 쓰도록 바꾸면 수탁자에 추가해야 합니다.
2. **위치기반서비스사업 신고 여부**: 위치를 서버로 받지 않아 수집에 해당하지 않는다는 해석으로 신고하지 않았습니다. 전문가 확인이 필요합니다.
3. **개인정보 "동의" 방식**: 지금 동의 화면은 "[필수] 개인정보 처리방침"에 동의받습니다. 2023년 개정 개인정보 보호법은 계약 이행에 필요한 처리는 동의 없이 가능하게 했으므로, 필수 동의 대신 "고지"로 바꾸고 선택 항목만 동의받는 방식이 더 맞을 수 있습니다.
4. **만 14세 미만 확인 수단 없음**: 약관으로 가입을 막지만 실제 나이 확인은 하지 않습니다. 카카오 연령대 정보 등으로 확인할지 검토가 필요합니다.
