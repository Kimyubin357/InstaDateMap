# 화면 점검 1차 (2026-11-25, iPhone 시뮬레이터 393×852)

iPhone 17 시뮬레이터 Safari로 지도·지역 목록·장소 상세·리스트·모음·검색·장소 추가·설정·알림·방 화면을 둘러보고, 링크 엣지 케이스를 넣어 봤습니다. 아래는 사용자 판단을 받아 고친 것과 보류한 것입니다.

## 고친 것
- **포커스 표시 전부 제거**: 굵은 초록·빨강 테두리와 포커스 그림자가 전체 디자인과 어울리지 않음(방 화면 제목, 링크 입력칸, 확인창 버튼 등). `fabric-theme.css` 맨 끝에서 모든 요소의 outline을 없앰.
- **지역 목록 시트**: "저장한 장소 7" 같은 소제목을 없애고 머리 높이를 줄임(상태 기능이 꺼진 동안).
- **지역 목록에서 연 장소 카드 번호**: 방 전체(9 / 52)가 아니라 그 지역 기준(1 / 2)으로, 넘기기도 그 지역 장소만.
- **둘이 쓰던 시절 문구**: 우리 설정→설정, 둘만의 메모→메모, 함께 가볼 곳→분류, 둘 다 저장함→N명이 저장, 우리 모음→모음, 우리 지도에 저장된 곳→이 방에 저장된 곳, 우리 지도에 저장→이 방에 저장, 앱 설명 등.
- **설정**: 프로필을 '이 기기'에서 '계정'으로 옮김.
- **알림 설정**: 홈 화면 앱 안내가 두 번 나오던 것을 한 번으로(앱 알림 줄만), 이 기기에서 켤 수 없을 때는 '다시 확인'을 숨기고, 남는 경우엔 바로 위 줄 아래에 붙임.
- **장소 상세**: '모음에 담기'·'다른 방에 담기'를 한 줄 두 칸으로(인스타 그라데이션 버튼은 의도한 디자인이라 유지).
- **링크 엣지 케이스**
  - 인스타가 아닌 링크·계정(프로필) 주소는 서버로 보내지 않고 입력칸 아래에서 바로 안내, 넣은 글은 지우지 않음.
  - 글과 섞인 링크("여기 꼭 가보자!! https://…")는 링크만 골라 보내서 카드에 문장 대신 링크가 보임.
  - 실패 화면의 '원인 · …' 꼬리표 제거, "~아닙니다" 말투를 "~아니에요"로.

## 그대로 둔 것(의도)
- 검색에서 직접 '+ 담기'로 저장하는 것: 이렇게 만든 기능.
- 장소 상세의 인스타 그라데이션 버튼: 일부러 둔 디자인.
- Safari에서 시트 맨 아래 문구가 도구 막대에 가리는 것: 홈 화면 앱에서는 문제 없음.

## 보류(나중에 다시 볼 것)
1. **방을 바꾼 뒤 지도 위치**: 이전 위치에 머물러 그 방 장소가 한눈에 안 보이고, 지역 카드가 하단 탭·+ 버튼 뒤에 깔림. 사용자가 상황을 이해하지 못해 설명이 필요.
2. **'삭제한 장소' 설명 문구**("복구하거나 영구 삭제해요"): 지금 동작은 '나만 보는 기록'이라 문구가 다름. 설명 필요.
3. **방 아이콘·색 중복 규칙**: 이미 있는 방과 같은 색·아이콘을 쓰지 않게 할지 — 규칙은 나중에.
4. **리스트**: 카카오 분류 원문('목욕탕,사우나'), '미분류 49'의 뜻, 지도/리스트 필터 위치 차이, 모음 탭의 '+ 새 모음'과 + 버튼.
5. **장소 추가 화면**: 단축어 받기 링크(단축어는 마지막에), '지금 보고 있는 방/마지막에 저장한 방'을 글로 안내하는 방식 — 더 나은 표현이 정해지지 않음.
6. **'이 링크 정리' 확인창**: 위치 핀 아이콘, 정리 뒤 완료 안내 없음 — 확인창이 무엇인지 설명 필요.
