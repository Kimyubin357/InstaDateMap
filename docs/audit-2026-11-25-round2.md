# 화면 점검 2차 (2026-11-25, iPhone 17 시뮬레이터 · 로컬 실데이터)

범위: 지도(전체·방 안) · 방 버튼 · 내 방 시트 · 지역 카드 · 장소 미리보기·상세 · 리스트(전체 장소·방·모음·모음 상세) · 장소 추가·저장할 방 · 설정 → 방 · 방 설정 · 알림 설정.
번호는 결정용입니다.

**처리 기록(2026-11-25):** 3번 검색창 → "[방 이름]에서 검색". 9번 → 담기(복사)를 옮기기로 바꿈(022). 13번·16번 → 전체 보기 `fit`, 옮기기 `moveRoom`, 모음 `collection` 아이콘. 11번(+)·14번(전체)은 사용자 판단으로 그대로 둠. 다음 계획: 2번 방·모음 구분.

## A. 사용자가 짚은 것

1. **내 방 시트에 방 설정이 없음.** 방 이름·색·멤버·초대는 설정 → 방 바꾸기·관리 → 톱니로 세 번 들어가야 합니다. 카드에서 바로 갈 길이 없습니다.
2. **방과 모음이 헷갈림.**
   - 같은 자리: 리스트 맨 위 오른쪽 탭이 전체에서는 "방", 방 안에서는 "모음"입니다.
   - 같은 모양: 둘 다 2열 카드 + 같은 점선 "새 ○○" 카드입니다.
   - 같은 색: 방과 모음이 같은 10색을 씁니다(빨간 방 안의 빨간 모음).
   - 장소 상세: "모음에 담기 | 다른 방에 담기"가 같은 모양 버튼으로 나란히 있습니다.

## B. 쓰기 불편한 점(UX)

3. **지금 어느 방인지 이름이 안 보임.** 방 버튼은 색 동그라미뿐이고, 검색창은 "이 방에서 검색"입니다. 방을 바꿀 때 토스트가 잠깐 뜨고 사라집니다.
4. **방을 바꿀 때마다** 화면 가운데에 큰 "장소를 불러오는 중…" 창과 어두운 덮개가 뜹니다(무거움).
5. **장소 추가 화면 문구가 틀림.** 전체 보기에서 들어와도 "지금 보고 있는 방 · 2명"이라고 나옵니다. 실제로는 마지막에 저장한 방입니다.
6. **설정 → 방 목록의 "보는 중" 배지**가 전체 보기 중에도 마지막 방에 붙어 있습니다.
7. **장소 추가 하단 "다음엔 인스타에서 바로 보내요"**는 단축어 안내입니다. 단축어는 맨 뒤로 미뤘고, 새 사용자는 설치할 방법이 없습니다.
8. **방 고르는 화면이 세 가지 모양입니다.**
   - 내 방 시트: 색 카드
   - 저장할 방 시트: 색 막대 목록
   - 설정 → 방: 색 막대 목록 + 톱니
9. **저장할 방 시트 안내가 실제 동작과 다름.** 안내는 "'다른 방에 담기'로 옮겨 담을 수 있어요"인데, 실제 동작은 복사(원래 방에도 남음)입니다.
10. **방 설정 화면의 저장 방식이 섞여 있음.**
    - 이름·색은 아래 "저장" 버튼으로 저장합니다.
    - 방장 넘기기·내보내기·초대는 누르면 바로 적용됩니다.
    - "방 나가기" 아이콘이 뒤로 가기와 같은 `<`입니다.
11. **같은 화면에서 + 가 세 가지 뜻.** 모음 탭과 모음 상세에서:
    - 빨간 + : 인스타 링크로 새 장소 추가
    - "+ 장소 담기": 저장된 장소를 모음에 넣기
    - "새 모음": 모음 만들기
12. **리스트 "미분류 49" 칩**의 뜻(모음에 안 넣은 장소)이 잘 안 읽힙니다.

## C. 디자인 통일성

13. **지도 아이콘 하나가 네 가지 뜻입니다.**
    - 지도 탭
    - 전체 보기(저장한 장소 다 보이게) 버튼
    - 다른 방에 담기
    - 모음 "지도에서 보기"
14. **"전체"가 세 가지 뜻입니다.**
    - 모든 방 범위
    - 지도 "전체 보기" 버튼
    - 리스트 "전체 장소"
15. **지역 카드 모양이 범위마다 다름.** 전체 보기는 크림 카드 + 막대, 방 안은 방 색으로 꽉 찬 말풍선입니다.
16. **하트 아이콘의 뜻이 여러 개.** 모음에 담기·불러오는 중·온보딩 첫 장에 하트를 씁니다. 모음 표지는 이모지입니다.
17. **분류 글자가 들쭉날쭉.**
    - 카카오 원문 그대로 "목욕탕,사우나", "관광,명소"처럼 쉼표가 붙어 나옵니다.
    - 장소 상세 분류 칸에 "음식점 · 서울 영등포구"처럼 지역까지 들어가 두 줄로 깨집니다(주소와 겹침).
18. **담은 사람 문구가 화면마다 다름.** 리스트·미리보기는 "수민님이 저장", 상세는 "수민 / 발견한 사람"입니다.
19. **방 색 빨강·초록이 앱 강조색과 같음.** 빨강은 + 버튼·제목, 초록은 선택 테두리·체크와 같은 색입니다. 그래서 내 방 시트에서 "내 장소(초록)" 카드와 선택 표시가 잘 구분되지 않습니다.
20. **리스트 머리말이 화면마다 다름.**
    - 방 안 전체 장소: "저장한 장소 52곳 · 선택"
    - 전체 보기 전체 장소: 머리말 없음
    - 모음 탭: 큰 제목 "모음 2개"
    - 방 탭: 작은 라벨 "방 3개 · 10개까지"
21. **지도 장소 미리보기 카드 가운데가 텅 빔**(상태 버튼을 뺀 자리).
22. **지도 앱 버튼이 두 곳에 흩어짐.** 장소 상세에 "네이버 지도"(본문)와 "카카오맵 열기"(하단)가 따로 있습니다.
23. **"Copy link" 문구 불일치.** 링크 오류 문구는 "'링크 복사'로", 온보딩은 "Copy link"입니다.

## D. 예외 상황(엣지 케이스)

24. **방 카드를 길게 누르면 카드 글자가 선택됩니다**(파란 선택 손잡이가 뜸).
25. **구 단계 지역 카드가 많이 겹침.**
    - 서울에서 서대문·종로·마포·중구, 강남·서초·송파가 서로 겹칩니다.
    - 오른쪽 아래 카드는 + 버튼 밑에 숨습니다.
26. **방이 10개로 가득 차도 "새 방 만들기" 카드가 눌림.** 내 방 시트·리스트 방 탭의 카드가 그대로 눌리고, 방 페이지로 넘어가서야 "10개까지예요" 안내가 나옵니다.
27. **방 설정의 "방 정보를 불러오고 있어요…"**가 머리말 점선에 바로 붙어 있습니다(여백 없음).
28. 확인 못 한 것:
    - 마지막 방을 지운 뒤 지도 화면(DB는 방 0개를 허용함)
    - 초대 링크로 처음 들어온 사람의 첫 화면
    - 새 장소 시트(지금 새 장소가 없어 보지 못함)
    - 실기기 알림

## E. 사용자 입장에서 있으면 좋은 기능

- 내 방 시트에서 방 설정 바로 가기(카드의 ⋯ 또는 길게 누르기) — 1번
- 지도·리스트 맨 위에 지금 방 이름 — 3번
- "OO님이 이미 저장한 곳이에요" 중복 안내(이미 할 일 목록에 있음)
- 장소 상세에 이 장소가 들어 있는 모음 표시
- 방 순서 바꾸기·자주 쓰는 방 맨 앞에 두기(방이 10개까지라서)
- 전체 리스트에서 여러 개 선택·삭제(이미 할 일 목록에 있음)
